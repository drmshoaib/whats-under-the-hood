# Published lectures

This directory contains only lectures that have been released publicly as part of the **What's Under the Hood?** LinkedIn series.

Each lecture uses the following layout:

```text
lectures/
└── 01-linear-regression/
    ├── index.html
    ├── assets/
    └── code/
```

The `index.html` file is the public lecture page. Supporting figures, data and code stay inside the lecture directory where practical so that each release remains self-contained.

Unreleased lectures are intentionally excluded from this repository.
