Linear Regression

What does fit() actually solve?

Dr. Muhammad Shoaib · Applied Mathematics & Data Science

The question behind fit()

A linear regression model can be fitted in one line:

from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X, y)

The API is deliberately simple. The computation underneath it is a compact piece of applied mathematics: an optimisation problem, an orthogonal projection and a numerical linear-algebra problem are all hiding inside fit().

This lecture follows that chain. The aim is to understand what is solved, why the familiar closed form appears, and why good software usually does not evaluate that closed form literally.

1. The least-squares objective

For $n$ observations and $p$ predictors, write the linear model as

$$y=X\beta+\varepsilon,$$

where $X\in\mathbb{R}^{n\times(p+1)}$ contains a column of ones if an intercept is fitted, $\beta$ is the coefficient vector and $\varepsilon$ is the error vector.

Ordinary least squares chooses the coefficients that minimise the squared Euclidean length of the residual vector:

$$\hat\beta=\arg\min_{\beta}\;\|y-X\beta\|_2^2.$$

Equivalently, it minimises

$$\operatorname{RSS}(\beta)=\sum_{i=1}^{n}(y_i-x_i^\top\beta)^2.$$

The square matters. It gives a smooth convex quadratic objective, weights large residuals strongly, and under independent Gaussian errors makes least squares identical to maximum-likelihood estimation.

2. From the loss to the normal equations

Expand the objective:

$$\operatorname{RSS}(\beta)=y^\top y-2\beta^\top X^\top y+\beta^\top X^\top X\beta.$$

Differentiating with respect to $\beta$ gives

$$\nabla_\beta\operatorname{RSS}=-2X^\top y+2X^\top X\beta.$$

At the minimum the gradient is zero, hence

$$X^\top X\hat\beta=X^\top y.$$

These are the normal equations. If $X$ has full column rank, $X^\top X$ is invertible and algebra gives

$$\hat\beta=(X^\top X)^{-1}X^\top y.$$

This expression is mathematically useful. It tells us how the estimator depends on $X$ and $y$, and it leads directly to results such as $\operatorname{Var}(\hat\beta)=\sigma^2(X^\top X)^{-1}$ under the classical homoscedastic model.

It should not, however, be read as an instruction to calculate an inverse in production code.

3. The geometry: least squares is a projection

Every fitted vector $X\beta$ lies in the column space of $X$. Usually the observed target vector $y$ does not. Least squares therefore asks for the reachable vector closest to $y$.

The normal equations can be rearranged as

$$X^\top(y-X\hat\beta)=0.$$

Thus the residual $e=y-\hat y$ is orthogonal to every column of $X$. The fitted vector $\hat y=X\hat\beta$ is the orthogonal projection of $y$ onto $\operatorname{col}(X)$.

This picture explains the word normal: the residual is normal to the subspace spanned by the predictors.

4. Why we do not compute $(X^\top X)^{-1}X^\top y$

The textbook formula hides a numerical problem. Forming $X^\top X$ squares the 2-norm condition number:

$$\kappa_2(X^\top X)=\kappa_2(X)^2.$$

If two predictors are nearly linearly dependent, $X$ is ill-conditioned. Forming $X^\top X$ makes that problem substantially worse. Explicit matrix inversion then adds unnecessary work and additional floating-point error.

Practical rule. Derive with the normal equations; solve with a least-squares routine based on a stable factorisation such as QR or SVD.

For an SVD

$$X=U\Sigma V^\top,$$

the least-squares solution can be written using the Moore–Penrose pseudoinverse:

$$\hat\beta=X^+y=V\Sigma^+U^\top y.$$

The singular values in $\Sigma$ expose rank deficiency directly. This route also gives a well-defined minimum-norm solution when the least-squares minimiser is not unique.

5. A worked example by hand

Take three observations:

$$ (x,y)=(1,2),(2,2),(3,4). $$

For simple linear regression $\hat y=\beta_0+\beta_1x$,

$$\bar x=2,\qquad \bar y=\frac83.$$

The slope is

$$\hat\beta_1=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2}=\frac{2}{2}=1,$$

and the intercept is

$$\hat\beta_0=\bar y-\hat\beta_1\bar x=\frac23.$$

So

$$\hat y=\frac23+x.$$

The fitted values are $5/3,8/3,11/3$ and the residuals are $1/3,-2/3,1/3$. Their sum is zero because an intercept is present; the residual vector is also orthogonal to the predictor column, exactly as the normal equations require.

6. When coefficients explode but predictions still look fine

Multicollinearity is one of the clearest examples of why the linear-algebra view matters. Suppose

rng = np.random.default_rng(7)
n = 80
x1 = rng.normal(size=n)
x2 = x1 + 1e-6 * rng.normal(size=n)
X  = np.column_stack([x1, x2])
y  = 3*x1 + 0.05*rng.normal(size=n)

Here $x_2$ is almost a copy of $x_1$. A least-squares fit gives coefficients approximately

$$\hat\beta_1\approx 5900.64,\qquad \hat\beta_2\approx -5897.65.$$

Individually they look absurd. Their sum is about $2.992$, close to the true effective slope $3$, and the fitted RMSE is only about $0.0458$.

The design matrix has $\kappa_2(X)\approx2.12\times10^6$, while $\kappa_2(X^\top X)\approx4.49\times10^{12}$. Tiny perturbations can therefore cause large changes in the separate coefficients even while predictions remain stable.

Interpretation. Multicollinearity is primarily a coefficient-identification and variance problem. It need not destroy predictive accuracy inside the region supported by the data.

7. What Python actually does

A from-scratch implementation should solve the least-squares problem directly rather than explicitly forming the inverse:

import numpy as np

def fit_ols(X, y, fit_intercept=True):
    X = np.asarray(X, dtype=float)
    y = np.asarray(y, dtype=float)

    if fit_intercept:
        X = np.column_stack([np.ones(len(X)), X])

    beta, residuals, rank, singular_values = np.linalg.lstsq(
        X, y, rcond=None
    )
    return beta, rank, singular_values

numpy.linalg.lstsq returns the vector that minimises $\|y-X\beta\|_2$; if several minimisers exist, it returns the one with the smallest Euclidean norm.

For dense data, current scikit-learn LinearRegression also formulates the problem as ordinary least squares and delegates the numerical solve to scipy.linalg.lstsq. Sparse data use a different least-squares solver. The estimator additionally exposes the matrix rank and singular values for dense $X$.

from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)

print(model.intercept_)
print(model.coef_)
print(model.rank_)
print(model.singular_)

The important distinction is between the estimator and the solver. Ordinary least squares defines the minimiser. QR, SVD and iterative least-squares methods are numerical routes to that minimiser.

8. What assumptions belong to which claim?

A useful way to avoid confusion is to separate fitting, unbiasedness, efficiency and inference.

ClaimWhat is needed
OLS coefficients minimise RSSNo probabilistic assumption. This is an optimisation statement.
Unique coefficient vectorFull column rank of $X$.
$\mathbb E[\hat\beta\mid X]=\beta$Correct linear mean specification and $\mathbb E[\varepsilon\mid X]=0$.
Gauss–Markov efficiency among linear unbiased estimatorsZero conditional mean plus homoscedastic, uncorrelated errors.
Exact small-sample $t$ and $F$ inferenceClassical assumptions plus normally distributed errors.

For prediction work, cross-validated error is usually the relevant test. For coefficient interpretation and uncertainty, the error structure and data-generating assumptions matter directly.

9. Under the hood

  • fit() solves $\min_\beta\|y-X\beta\|_2^2$.
  • The normal equations arise by setting the gradient of RSS to zero.
  • Geometrically, $\hat y$ is the orthogonal projection of $y$ onto $\operatorname{col}(X)$.
  • The closed-form inverse is a mathematical identity, not the preferred numerical algorithm.
  • QR/SVD-style least-squares solvers handle conditioning and rank more sensibly.
  • Multicollinearity can make individual coefficients unstable while predictions remain accurate.

The next time LinearRegression().fit(X, y) returns almost instantly, there is a useful mental picture behind that call: a convex quadratic objective, a projection in $\mathbb R^n$, and a carefully implemented least-squares solve.
